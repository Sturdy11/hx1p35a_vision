# 板卡控制与信号

器件 PH1P35MDG324，速度等级 -3。全部电气约束以 [pin.adc](pin.adc) 为准，时钟约束见 [video.sdc](video.sdc)。

| 逻辑信号 | 管脚 | 用途 |
|---|---|---|
| KEY1 / I_key_n[0] | D5 | 下一个显示模式 |
| KEY2 / I_key_n[1] | A9 | 上一个显示模式 |
| KEY3 / I_key_n[2] | B9 | 叠加开关 |
| KEY4 / I_key_n[3] | C7 | 短按手动轮选；长按两步基准保存 |
| SW1 / I_sw[0] | A4 | 清点使能，低有效 |
| SW2 / I_sw[1] | B4 | 识别使能，低有效 |
| I_sw[2] | E11 | 参数位 2 |
| I_sw[3] | D11 | 参数位 3 |
| I_button[0] | N2 | 目标存在输出 |
| I_button[1] | J14 | 清点报警输出 |

`I_button` 是保留的接口名称，这两个信号在当前顶层作为输出使用。板上丝印可能采用 KEY5~KEY8 等命名，以 FPGA 管脚和实际接线对应。旧注释中把 J14 写成心跳、把 SW2 写成 SW6 的描述不适用于当前接线。

清点流程：同时使能清点与识别，移开遮挡物，长按 KEY4 约 1 秒后松开，等待 CAND 变为 CHECK，核对 S/T/H/G/C/N 六类待保存数量，再次长按确认 BASE。LOW 光照状态仍需满足质量和多次观察条件。进入原图、关闭使能或复位会清除 BASE。

MOVE 表示已确认的同类别目标发生足够位移；小幅位移也会更新坐标。HOLD 使用上一次位置，并非新的测量。
