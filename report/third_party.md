# 第三方来源与许可

| 内容 | 来源与处理 |
|---|---|
| src/ip/ | 安路 TD 生成的 PLL、FIFO、RAM、DDR2 配置及实现；保留模块标识和加密内容 |
| src/rtl/mipi_dphy_rx/ 与 HDMI 加密模块 | 板卡示例中的厂商 IP；按原加密形式保留 |
| src/rtl/isp/、uics500_cfg/ 等基础模块 | 板卡配套示例及米联客模块；原有版权和许可声明保留 |
| src/rtl/imgproc/、顶层及帧缓存管理改动 | 当前 V116 项目的集成、识别、跟踪、清点和显示逻辑 |
| data/fixtures/ | 项目诊断裁剪和合成仿真场景；用于回归，非完整训练数据集 |

文件路径的小写化与注释清理不改变模块来源。厂商文件、版权、综合指令和加密块没有被替换成新的许可；仓库未添加覆盖全仓库的开源许可证。发布范围与使用方式按原文件许可和赛题提交要求处理。
